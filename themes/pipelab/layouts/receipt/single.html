Verify it yourself

Download the receipt JSON, pin the public key, run any verifier. Exit code 0 is accept; 1 is reject; 2 is verifier error; 64 is usage error.

1. Get the receipt

curl -O https://pipelab.org/receipts/v0/{{ $receiptFile }}

2. Verify with the Pipelock binary (Go)

pipelock verify-receipt \
  --key {{ $key.public_key_hex }} \
  {{ $receiptFile }}

3. Or use the standalone verifier

pipelock-verifier receipt \
  --key {{ $key.public_key_hex }} \
  {{ $receiptFile }}

4. Or one of the language SDKs

After installing a language verifier, the same pinned-key check works:

pipelock-verifier-ts receipt \
  --key {{ $key.public_key_hex }} \
  {{ $receiptFile }}
pipelock-verifier-rs receipt \
  --key {{ $key.public_key_hex }} \
  {{ $receiptFile }}
pipelock-verify \
  --key {{ $key.public_key_hex }} \
  {{ $receiptFile }}

Verifier source for all four implementations is documented at /learn/verify-a-receipt/.
