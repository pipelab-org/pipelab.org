The enforceable boundary

Route it. Inspect it. Prove it.

An agent firewall only covers traffic it actually mediates. The deployment creates that boundary; inspection makes the decision; the receipt makes the result checkable.

01 Mediate

Put the control in the path

Route HTTP and WebSocket traffic through the proxy, or launch stdio MCP servers through the wrapper.

02 Inspect

Read both directions

Scan requests, responses, tool arguments, and tool descriptions before the next system receives them.

03 Record

Keep a verifiable decision

When receipt signing is configured, emit a signed allow or block record that another party can verify offline.
